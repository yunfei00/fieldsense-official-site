# FieldSense 场感官网 MVP 产品需求

## 项目定位

FieldSense 场感官网面向硬件研发、EMC 测试、射频分析和实验室测试团队，展示近场扫描系统与电磁云图分析平台能力，并承接预约演示与咨询线索。

## 第一阶段目标

- 完成可运行的静态官网 MVP。
- 支持首页、产品中心、产品详情、解决方案、方案详情、案例中心、技术文章、联系我们、预约演示页面。
- 使用 Django 后端收集演示和咨询线索。
- 通过 Django Admin 查看、搜索、筛选和跟进线索。
- 提供基础 Docker Compose 部署配置。

## 核心用户

- 硬件研发工程师
- EMC 整改工程师
- 射频工程师
- 实验室测试负责人
- 采购和技术评估人员

## 关键转化路径

1. 用户从首页了解 FieldSense 的定位和核心能力。
2. 用户进入产品中心或解决方案页查看匹配场景。
3. 用户通过 CTA 进入预约演示或联系我们页面。
4. 用户提交表单，后端保存线索。
5. 销售或技术支持在 Django Admin 中跟进线索状态。

## 后续规划

- 接入 CMS 或 Django API 管理文章、案例和资料下载。
- 增加 SEO 专题页和结构化数据。
- 接入 PostgreSQL、对象存储和邮件通知。
- 增加资料下载、白皮书、案例详情和表单来源追踪。
